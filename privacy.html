Política de privacidad

English version below

Última actualización: 5 de octubre de 2026

Esta política describe cómo la aplicación yt-autoshorts ("la aplicación"), usada por Curiosidades en 45 segundos para publicar sus propios vídeos en YouTube, Facebook, Instagram y TikTok, trata la información.

Uso de los servicios de la API de YouTube

La aplicación utiliza los servicios de la API de YouTube. Al usarla aceptas las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Datos a los que accede

La aplicación solicita únicamente estos permisos, siempre sobre el canal de YouTube de su propietario:

  • youtube.upload: subir los vídeos del canal.
  • yt-analytics.readonly: leer estadísticas agregadas de los vídeos del propio canal (visualizaciones, porcentaje medio visto, "me gusta" y suscriptores ganados) para decidir qué temas y formatos publicar.

Las estadísticas se usan solo durante la ejecución y no se guardan. La aplicación no accede a datos de otros usuarios de YouTube, ni a comentarios o información personal de los espectadores.

Facebook e Instagram

La aplicación usa la API Graph de Meta con los permisos pages_show_list, pages_read_engagement, pages_manage_posts, publish_video, business_management, instagram_basic e instagram_content_publish, exclusivamente para publicar Reels en la página de Facebook y la cuenta de Instagram del propietario. No lee datos de otros usuarios.

TikTok

La aplicación usa Login Kit y la Content Posting API de TikTok con los permisos user.info.basic y video.publish, exclusivamente para publicar vídeos en la cuenta de TikTok del propietario (@curiosidadesen45segundos). Solo consulta la información básica del creador necesaria para publicar (nombre y opciones de privacidad). Los vídeos se etiquetan como contenido generado con IA. El acceso puede revocarse en TikTok desde Ajustes → Seguridad → Aplicaciones y servicios.

Almacenamiento y compartición

Las credenciales OAuth del propietario se guardan cifradas como secretos del repositorio privado desde el que se ejecuta la aplicación. No se venden, comparten ni transfieren datos a terceros. No se usan cookies ni sistemas de analítica.

Conservación y eliminación de datos

La aplicación no almacena datos de las APIs de YouTube, Meta ni TikTok. Las únicas credenciales guardadas son las del propietario del canal; al revocar el acceso o escribir al contacto indicado, se eliminan en un plazo máximo de 7 días.

Revocar el acceso

Puedes revocar el acceso de la aplicación en cualquier momento desde la página de permisos de tu cuenta de Google.

Contacto

Para cualquier consulta: david.glez.lomena@gmail.com

Privacy Policy (English)

Last updated: October 5, 2026

This policy describes how the yt-autoshorts application ("the app"), used by Curiosidades en 45 segundos to publish its own videos on YouTube, Facebook, Instagram and TikTok, handles information.

Use of YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.

Data accessed

The app only requests these scopes, always for its owner's own YouTube channel:

  • youtube.upload: upload the channel's videos.
  • yt-analytics.readonly: read aggregated statistics of the channel's own videos (views, average view percentage, likes and subscribers gained) to decide which topics and formats to publish.

Statistics are only used while the app runs and are not stored. The app does not access data about other YouTube users, nor viewers' comments or personal information.

Facebook and Instagram

The app uses the Meta Graph API with the pages_show_list, pages_read_engagement, pages_manage_posts, publish_video, business_management, instagram_basic and instagram_content_publish permissions, only to publish Reels to its owner's Facebook Page and Instagram account. It does not read other users' data.

TikTok

The app uses TikTok Login Kit and the Content Posting API with the user.info.basic and video.publish scopes, only to publish videos to its owner's TikTok account (@curiosidadesen45segundos). It only reads the basic creator information required to post (display name and privacy options). Videos are labelled as AI-generated content. Access can be revoked in TikTok under Settings → Security → Apps and services.

Storage and sharing

The owner's OAuth credentials are stored encrypted as secrets of the private repository the app runs from. No data is sold, shared or transferred to third parties. No cookies or analytics are used.

Data retention and deletion

The app does not store any data from the YouTube, Meta or TikTok APIs. The only stored credentials belong to the channel owner; they are deleted within 7 days after access is revoked or upon request to the contact below.

Revoking access

You can revoke the app's access at any time from the Google account permissions page.
